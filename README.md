# CiteWise downloads

CiteWise brings papers, reading notes and references together in a Windows app.

This repository contains packaged Windows releases and their SHA-256 checksums.

## Windows preview

[Download CiteWise 1.17.1 for Windows](https://github.com/chiya1998/citewise-downloads/releases/download/v1.17.1-preview/CiteWise-Setup-1.17.1.exe)

- Windows 10 build 17763 or later, or Windows 11; 64-bit (x64).
- 81.7 MB download; the app runtime is included.
- This preview is unsigned. Windows may show an unknown-publisher warning. If installation is blocked, contact CiteWise or your organisation's IT team.
- Save your work and close CiteWise, Word and PowerPoint before installing. Back up an existing library first.
- Microsoft Store distribution and automatic updates are still in preparation. iOS is coming soon.
